# 💸 Student Expense Tracker

A beginner-friendly web app that helps students record expenses, track monthly spending, and manage a budget.

## Features
- Add and delete expenses
- Categorize spending into Food, Travel, Education, Shopping, and Other
- Select a month to view its expenses
- Set a separate budget for each month
- View the remaining budget and overspending warnings
- See category-wise totals and a simple spending bar chart
- Save expenses and budgets in browser `localStorage`

## Built With
- HTML
- CSS
- JavaScript
- Browser `localStorage`

## Run the Project
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

No extra libraries are required.

## Data Storage
Expenses and budgets are stored in the browser on the device you use. They do not automatically sync across devices. Clearing the browser's site data may delete saved information.

## What I Practiced
DOM manipulation, functions, arrays, objects, event handling, validation, dates, calculations, and `localStorage`.
